# Claude Desktop MCP Setup Guides

Step-by-step guides to connect Claude Desktop to Salesforce using MCP (Model Context Protocol). Once set up, you can run SOQL queries and read any Salesforce object — Cases, Accounts, Contacts — directly from a Claude Desktop chat.

---

## [Salesforce DX MCP Setup](salesforce-dx)

Connect Claude Desktop to any Salesforce org.

- One-time terminal setup — authorize your org once, never again
- Run SOQL queries on any Salesforce object from chat
- Read-only by default — safe for production orgs
- Works with any company's Salesforce instance
